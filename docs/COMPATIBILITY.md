# Compatibility and independence

Ropiq is an independent project. It is not affiliated with, endorsed by, sponsored by, or an official distribution of any supported backend vendor.

## Product boundary

- Ropiq implements its own server, interface, planning logic, validation, approvals, and records.
- Backends run as separate processes selected, installed, licensed, and controlled by the user.
- Communication is limited to documented network endpoints configured by the user.
- Ropiq does not patch, embed, redistribute, or automatically launch third-party backends.
- Compatibility names are used only to identify the external system selected by the user.

## Prohibited repository content

Do not add third-party source code, logos, screenshots, interface assets, model weights, custom nodes, workflows, templates, runtimes, drivers, or documentation unless the project has a documented written right to redistribute the exact material.

New adapters must include a license and provenance review before release.
