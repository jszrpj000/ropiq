# Free and open model

Ropiq's local creative core is free and open source. Users can create projects, connect their own model API, connect local or cloud generation hardware, install compatible extensions, and keep their production records without paying Ropiq a subscription or feature-unlock fee.

## Free core commitment

- The conversation agent, AI drama workflow, product-video workflow, project storage, validation, approvals, and backend adapters remain available in the open-source application.
- Ropiq will not deliberately degrade local generation, add watermarks to user media, cap project counts, or lock export behind payment.
- Users pay only the third parties they independently choose, such as a model API, cloud GPU provider, licensed model, music library, or extension author.
- Advertisements will never be inserted into prompts, scripts, project files, generated media, local history, or exports.

## Possible future revenue

- Clearly labeled advertisements may appear only in optional discovery surfaces such as a public extension marketplace or learning center.
- A future marketplace may charge extension publishers a disclosed transaction commission. Free and manually installed extensions remain supported.
- Sponsored placement must be labeled, must not affect automatic workflow ranking, and must pass the same security and license checks as non-sponsored entries.

There are no advertisements or paid marketplace features in the current alpha. Any future networked discovery feature must be optional, disclose what data it sends, and work without uploading private creative content.
