Ropiq 新手使用说明

Ropiq 是对话式 AI 短剧和商品视频制作智能体。你用大白话说明想做什么，它负责规划步骤、选择可用节点和参数；真正的图像、视频与音频计算由你连接的本机或算力云生成后端完成。

第一次打开

  1. 双击桌面的 Ropiq 图标。
  2. 在配置向导中填写你自己的大模型 API。使用 DeepSeek 时，接口类型选 OpenAI 兼容，API 地址通常填 https://api.deepseek.com，模型名称和密钥按你的账号填写。
  3. 在“生成后端”填写 ComfyUI 地址。可以先跳过，进入软件后再修改。
  4. 如果要在本机执行字幕、剪辑、质检和成片，填写你自己合法取得的 ffmpeg.exe 完整路径；暂时不需要可以留空。
  5. 点击 测试模型，成功后点击 保存并进入。

密钥安全：只在 Ropiq 本机配置页填写密钥，不要把密钥发到聊天、截图、GitHub 或说明文档中。Ropiq 不附带第三方模型、节点或算力。

可选：配置本机媒体工具

为了降低公开安装包的第三方再分发风险，Ropiq 不捆绑 FFmpeg。这不影响小说解析、剧本、人物、场景、分镜、提示词和云端节点图生成；只有本机字幕、剪辑、解码质检与最终成片需要它。

  1. 从你信任且有权使用的来源取得适合 Windows 的 FFmpeg，并阅读该发行版本附带的许可证。
  2. 找到它的实际程序文件，例如 C:\Tools\ffmpeg\bin\ffmpeg.exe。要填写的是完整文件路径，不是文件夹。
  3. 在 Ropiq 的“连接与配置 → 本机媒体工具”粘贴路径并保存。
  4. 回到短剧制作台；本地媒体阶段显示可执行，说明路径已被识别。

FFmpeg 项目与许可证说明：官方获取页面、官方法律与许可证说明。Ropiq 不代替第三方发行方授予许可证。

方案一：连接本机 ComfyUI

  1. 先启动本机 ComfyUI，并在浏览器确认它能正常打开。
  2. 如果 ComfyUI 和 Ropiq 在同一台电脑，生成后端地址通常填写：
http://127.0.0.1:8188
  1. 回到 Ropiq 配置页，接口类型保持 ComfyUI，粘贴地址并保存。
  2. 进入制作台后查看后端状态。能读取节点、模型、显卡和队列信息，说明连接成功。

局域网连接：如果 ComfyUI 在另一台电脑，要填写那台电脑的局域网地址，例如 http://192.168.1.50:8188，并确保 ComfyUI 允许局域网访问且 Windows 防火墙已放行对应端口。不要把未加保护的 ComfyUI 端口直接暴露到公网。

方案二：连接算力云上的 ComfyUI

  1. 在算力平台创建或启动一个带 ComfyUI 的 GPU 实例。
  2. 等待实例状态变为“运行中”，点击平台提供的 WebUI / ComfyUI / 访问应用服务入口。
  3. 浏览器成功打开 ComfyUI 后，复制地址栏里的完整公网地址。常见形式如下：
https://实例专属域名:端口
  1. 把完整地址粘贴到 Ropiq 的 生成后端地址，末尾有没有 / 都可以。
  2. 如果平台为 WebUI 设置了访问令牌，在 Ropiq 的后端令牌栏填写；没有令牌就留空。
  3. 保存后确认 Ropiq 能读取后端节点和模型，再开始生成。

最可靠的找地址方法：不要复制实例列表页、JupyterLab、SSH 或后台管理页的地址。一定要先点开真正的 ComfyUI 页面，再复制该页面浏览器地址栏里的地址。实例关机、释放或重建后，公网地址可能改变，需要在 Ropiq 中重新保存。

连接失败时检查

  • 浏览器先测：同一台电脑的浏览器都打不开该地址时，Ropiq 也无法连接。
  • 实例状态：确认云实例处于运行中，而不是已关机、启动中或已释放。
  • 页面是否正确：地址打开后应看到 ComfyUI 节点界面，而不是登录页、JupyterLab 或平台控制台。
  • 本机端口：默认常见端口是 8188，但以你实际启动参数为准。
  • 模型与节点：连接成功只代表网络可达；工作流需要的模型或自定义节点仍要在后端正确安装。
  • 云费用：生成结束后到算力平台核对任务和计费状态。只有已经配置云平台状态、停止接口和令牌时，Ropiq 才能请求停止实例，而且停止前会再次要求确认。

开始对话

可以直接说：“把这篇小说改成 3 集竖屏短剧，写实电影风，每集 60 秒，先完成人物、场景和分镜，生成前让我确认。”

也可以进入“短剧制作”或“商品视频”工作台，按表单逐项填写。新手建议先用大白话描述目标，再在结构化页面检查人物、镜头、配音和生成参数。

独立性说明

Ropiq 是独立开源项目，不包含 ComfyUI、FFmpeg、第三方模型、插件、工作流、驱动或品牌素材，也不隶属于或代表 Comfy Org。Windows 安装包只附带运行 Ropiq 自身所需的 Node.js 及其完整许可证。请只安装你有权使用且来源可信的外部组件，并遵守各自许可证。
